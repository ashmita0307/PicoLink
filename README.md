# PicoLink

PicoLink is a project based on the **RP2040 microcontroller** focused on implementing VGA output and building a graphics-based application.

## Features

* VGA output using RP2040
* Custom VGA graphics library
* Increased color support
* PIO-based VGA signal generation
* DMA-assisted data transfer
* Space Invaders game

## Project Objective

The main objective of PicoLink was to implement VGA output on the RP2040 and understand graphics generation at a low level.

The project was further improved by **increasing the number of supported colors** and using the graphics library to develop a **Space Invaders game**.

## Hardware

* RP2040 / Raspberry Pi Pico
* VGA Display
* VGA Connector
* Resistors for RGB signals
* USB connection

## Software & Technologies

* C / C++
* Raspberry Pi Pico SDK
* PIO
* DMA
* VGA
* USB HID / CDC
* CMake

## Key Contributions

### VGA Implementation

Implemented VGA signal generation using the RP2040's **PIO state machines and DMA**.

### Improved Color Support

Modified the VGA implementation to support a greater number of colors.

### Space Invaders

Developed a **Space Invaders game** using the implemented VGA graphics system to demonstrate its practical use.
